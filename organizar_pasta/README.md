# organizar-pasta

Cria as subpastas de categorias que estiverem faltando dentro da pasta informada e, em seguida, move os arquivos para a categoria correspondente pela extensão.

## Uso

```powershell
organizar-pasta .
```

Por padrão, organiza a pasta Downloads do usuário. Para informar outro diretório:

```powershell
organizar-pasta "C:\Users\usuario\Downloads"
```

Categorias: `imagens`, `documentos`, `executaveis`, `videos`, `comprimidos`, `audios` e `codigo`.
